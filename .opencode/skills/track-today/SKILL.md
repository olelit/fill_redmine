# Трекинг дня по коммитам

1. Возьми `user_name` из `list_enabled_users` (или уточни у пользователя),
   `repo_path` — текущий репозиторий.
2. Вызови `prepare_youtrack_from_commits(user_name, repo_path)`.
   - **Не передавай `start`/`end`**: без них период — только сегодня.
   - `daily_hours` по умолчанию **8**. Передавай другое значение, только если
     пользователь явно назвал свою цифру.
3. Часы распределяются по интервалам между коммитами. **Никогда не распределяй
   часы вручную** и не подменяй расчёт своими оценками.
4. Покажи пользователю план: период, записи (issue, часы, комментарий) и все
   `warnings`.
5. Вызови `write_plan` с `plan_id` из ответа.

Без явного подтверждения (elicitation) **ничего не записывай**. Если
`write_plan` вернул `blocked`, покажи причину и остановись.

Если коммитов нет или в них нет issue — не выдумывай часы, а покажи `warnings`
из плана.
